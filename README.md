# Brendan Mayer Media

Portfolio site for Brendan Mayer, a concert, festival, event and sports photographer based in Victoria, BC.
Built with [Astro](https://astro.build) as a static site and hosted free on GitHub Pages.

## Quick start

Requires Node 24 or newer (see `.nvmrc`).

```sh
npm install
npm run dev        # local site at http://localhost:4321/brendan-mayer-media/
```

| Command           | What it does                                                       |
| ----------------- | ------------------------------------------------------------------ |
| `npm run dev`     | Local development server with live reload                          |
| `npm run photos`  | Prepares new photos from `incoming/` (see `docs/ADDING-PHOTOS.md`) |
| `npm run build`   | Type-checks, then builds the site into `dist/`                     |
| `npm run preview` | Serves the built `dist/` locally, exactly as it will be published  |
| `npm run lint`    | ESLint                                                             |
| `npm run format`  | Prettier (`format:check` only reports)                             |

## How it's organised

```
incoming/                  full-resolution originals (gitignored, never published; keep a backup!)
scripts/prep-images.mjs    resizes originals, strips GPS/camera metadata, adds copyright
src/
  assets/galleries/<name>/ web-ready photos per gallery (output of npm run photos)
  assets/about/            Brendan's portrait
  assets/site/             other site images (contact background)
  content/galleries/*.yaml one file per gallery: label, order, blurb, optional photo captions
  data/site.ts             site copy: tagline, about text, services, email, Instagram
  components/              Header, HeroCarousel, WorkTabs, GalleryGrid, Lightbox, About, Services, ContactCTA, Footer, SEO
  layouts/BaseLayout.astro page shell (fonts, header, footer, photo viewer)
  pages/                   index, galleries/[gallery], 404, robots.txt
  styles/tokens.css        design tokens (colours, type, spacing, radii)
```

- **Adding photos:** see [`docs/ADDING-PHOTOS.md`](docs/ADDING-PHOTOS.md).
- **Adding a gallery:** create `incoming/<name>/` and `src/content/galleries/<name>.yaml` (copy an existing one), then run `npm run photos`. It appears in the tabs, footer and its own page automatically. Add a service card in `src/data/site.ts` if needed.
- **Editing text:** most copy lives in `src/data/site.ts`; gallery descriptions and captions live in the YAML files.

## Deploying

Every push to `main` runs `.github/workflows/deploy.yml`: lint, format check and `npm audit`, then type check and build, then publish to GitHub Pages.
In the repo settings, **Pages → Source** must be set to **GitHub Actions**.

### Moving to the custom domain

1. Buy `brendanmayermedia.ca` (or `.com`) at Namecheap. Turn on auto-renew, the transfer lock, 2FA and DNSSEC.
2. In GitHub: **Settings → Pages → Custom domain**, and verify the domain under your account's **Pages** settings (this prevents domain takeover).
3. In Namecheap DNS, add GitHub's `A`/`AAAA` records for the apex domain and a `CNAME` for `www` pointing to `amesmimi.github.io`.
4. In `astro.config.mjs`, set `SITE` to `https://brendanmayermedia.ca` and `BASE` to `/`, and add `public/CNAME` containing `brendanmayermedia.ca`.
5. Once the certificate is issued, tick **Enforce HTTPS**.

## Security and image protection

- Static site: no server, database or login.
- A strict Content Security Policy is generated by Astro (`security.csp` in `astro.config.mjs`) and written into each page as a `<meta>` tag, because GitHub Pages can't set HTTP headers. All scripts and styles are self-hosted and hashed.
- Fonts are self-hosted; the site makes no third-party requests and sets no cookies.
- Published photos are capped at 2400px, stripped of GPS and camera serial data, and stamped with Brendan's copyright in EXIF.
- Right-click saving, dragging and the iOS long-press save are disabled on photos (deterrents only).
- `robots.txt` and `noai` meta tags ask AI crawlers not to use the photos.
- GitHub Actions are pinned to exact commits, with least-privilege permissions. Dependabot proposes weekly dependency updates.
